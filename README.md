# java-racingcar-precourse

# [화면]

## 입력

- [X] : 경주할 자동차 입력 받기 (이름은 쉼표(,) 기준으로 구분)
- [X] : 시도할 횟수 입력 받기

## 출력

- [X] : 차수별 실행 결과 출력 하기
- [X] : 우승자 안내 문구 출력 하기

# [기능]

- [X] : 입력받은 자동차만큼 자동차 등록하기
- [X] : 0에서 9 사이에서 무작위 값 생성 및 자동차 전진하기 (0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우)
- [X] : 자동차들의 현재 위치 나타내기
- [X] : 최종 우승자 판별하기

# [예외처리]

- [X] : 이름이 비어 있거나 중복일 경우 예외처리
- [X] : 이름 길이 5자 초과 시 예외처리
- [X] : 시도 횟수가 숫자가 아닐 경우 예외 (문자/음수 포함)
- [X] : 경주할 자동차 최소 2대 이상 입력 받기 (레이싱 경주라는 의미 충족 위해)
- [ ] : 만약 모든 자동차가 움직이지 않았을 시 전원 실격 처리 (레이싱 경주라는 의미 충족 위해)
- [X] : 자동차 30대 초과 등록, 시도횟수 100회 초과 시도 예외처리 (프로그램 처리시간, 메모리 효율, 콘솔 입력 버퍼 고려 등의 이유)
